V3 — Vendor Onboarding, Profile & Leads

This phase covers everything a vendor does before they've connected any payment method: building their listing, getting approved, and working incoming leads. It requires coordination between a vendor account and an admin account (for the approval steps) — have both logged in, ideally in two different browser profiles/incognito windows so sessions don't collide.
Before you start: a fresh vendor account from V1 (still in DRAFT status), plus admin access. You'll also want a couple account from V2 that has already sent this vendor a real enquiry, so the Leads section has live data to test against.
Not applicable — don't test these, they don't exist: a real calendar/date-blocking booking system (availability is a free-text field only), any AI-assisted profile writing, automated spam-scoring beyond a manual flag.
