> **Frontend Arch Phase 15**

## 1. Goal & Product Vision

Enable category-eligible wedding vendors to launch and manage a branded, lightweight e-commerce storefront with zero complex checkout friction:
1. **Admin Category Enablement (`/admin/categories-locations`)**:
   - Admins can toggle **Vendor Store** capability per category in `CatalogBoard.tsx`.
   - Visual toggle switch and status badge in each category row: `"Store: Enabled / Disabled"`.
2. **Vendor Store Management Suite (`/vendor/store`)**:
   - Gated dashboard route accessible only to eligible vendors (determined by live category check).
   - **Store Overview & Sharing**: Unique shareable link (`https://itsmykalyanam.com/store/[slug]`), copy link, WhatsApp broadcast, and downloadable high-res QR code generated locally offline via `qrcode`.
   - **Catalog & Inventory Manager**: Create, edit, and organize physical products, rentals, favors, stationery, and booking tokens with photos uploaded via the standard `Media` presigned upload pipeline, INR pricing, GST rate, and MOQ.
   - **Order Tracker & Invoicing**: Track order inquiries, contact customers via WhatsApp in one click, and convert confirmed orders into GST tax invoices (automatically carrying forward GST rates and customer place of supply).
3. **Public Storefront & Portfolio Integration**:
   - **Dedicated Standalone Store Route**: `/store/[slug]` with vendor-first branding, optimized WebP product galleries, and category filtering.
   - **Integrated Portfolio Tab**: Embedded as an optional `"Store / Shop"` tab directly inside the standalone digital portfolio (`/portfolio/[slug]?tab=store`).
   - **Interactive Mini-Cart Drawer & 1-Click WhatsApp Ordering**: Couples add items to cart, enter wedding date, delivery state/city, and customization notes, and place their order directly via WhatsApp or web submission.

## 2. User Flows & UX Architecture

### Flow A: Admin Category Control
```text
Admin accesses /admin/categories-locations
  → Views Category Row (e.g. "Favors & Return Gifts")
  → Toggles "Vendor Store" switch
  → Category updated via PATCH /api/v1/categories/:id { hasStoreEnabled: true }
  → All vendors under "Favors & Return Gifts" instantly unlock the Store module in their dashboard
```

### Flow B: Vendor Store Setup & Media Upload Pipeline
```text
Eligible Vendor logs into /vendor/dashboard
  → VendorShell checks vendor.categories.some(c => c.hasStoreEnabled)
  → "Store" tab is visible in header/sidebar
  → Navigates to /vendor/store
  → Sets store tagline, validated WhatsApp order phone (/^(?:\+91|91)?[6-9]\d{9}$/), shipping & return policies
  → Clicks "+ Add Product"
  → Uploads product photos through standard presigned R2 upload pipeline (mediaType: "STORE_ITEM_PHOTO")
  → Configures title, price, compare-at price, GST rate (e.g. 18%), MOQ, and stock quantity
  → Saves product; WebP variants generated by background media worker
  → Clicks "Share Store" to copy URL or download QR code for social media & visiting cards
```

### Flow C: Couple Browsing & 1-Click WhatsApp Checkout
```text
Couple opens vendor's shared link: /store/royal-gifts or /portfolio/royal-gifts?tab=store
  → Public page checks live category eligibility (404 if disabled)
  → Browses curated product grid with optimized WebP images, price, and MOQ
  → Adds items to Mini-Cart
  → Opens Mini-Cart Drawer
  → Enters Name, WhatsApp Phone, Wedding Date, Delivery City, and State (Place of Supply)
  → Clicks "Order via WhatsApp"
  → POST /api/v1/stores/:slug/orders (protected by storeOrderRateLimiter)
  → Order registered with atomic #ORD-2026-XXXX in DB
  → Automatically opens WhatsApp with formatted message:
      "Hello Royal Gifts! 🌸
       I'd like to place an order from your WedHub Store (Order #ORD-2026-0042):
       • Brass Thamboolam Box × 50 (₹350/pc) = ₹17,500
       Total Estimated: ₹17,500
       Wedding Date: 18 Nov 2026
       Delivery: Chennai, Tamil Nadu
       Name: Ananya (+91 98401 23456)"
  → Vendor receives message, reviews order in /vendor/store/orders
  → Vendor clicks "Create GST Invoice" → automatically maps state to placeOfSupply and line-item GST rates into Stage 9 invoice engine
```

## 3. Frontend Routes & Component Architecture

### 1. Admin Category Management (`wedhub-frontend-app`)
- **`app/(admin)/admin/categories-locations/CatalogBoard.tsx`**:
  - Extend `CategoryRow` to render a **"Vendor Store"** toggle button/switch.
  - Display green badge `"Store Enabled"` when active.
  - Wire to `updateCategory(id, { hasStoreEnabled: boolean })` with optimistic UI update.

### 2. Vendor Portal (`app/(vendor)/vendor/store/`)
- **`components/shared/VendorShell.tsx`**:
  - Conditionally render **"Store"** nav item based on live category eligibility (`categories.some(c => c.hasStoreEnabled)`).
- **`app/(vendor)/vendor/store/page.tsx`**:
  - Store Hub: Quick metrics (Total Products, Active Orders, Revenue), Live Store Link card with Share/QR modal, and Store Profile settings.
  - Form validation for `whatsappOrderPhone` with Indian phone regex and instant preview.
- **`app/(vendor)/vendor/store/items/page.tsx`**:
  - Item catalog data table with search, category filtering, stock toggle, and price columns.
- **`components/vendor-store/StoreItemModal.tsx`**:
  - Create/Edit item modal: Title, slug, description, itemType, price, compare-at price, GST rate (`0, 5, 12, 18, 28%`), MOQ, stock count.
  - Multi-image uploader wired into `lib/media/upload.ts` with `STORE_ITEM_PHOTO` type, displaying progress and WebP thumbnails.
- **`app/(vendor)/vendor/store/orders/page.tsx`**:
  - Order inquiry tracker: Status filter chips (All, Pending, Confirmed, Shipped, Completed).
  - Customer contact card with 1-click WhatsApp chat deep link.
  - "Generate GST Invoice" button pre-populating line items and `placeOfSupply` into Stage 9 `/vendor/invoices/new`.

### 3. Public Storefront & Portfolio Integration
- **`app/(public)/store/[slug]/page.tsx`**:
  - Standalone Server Component fetching vendor store data, branding, and active catalog items.
  - Renders SEO metadata with OpenGraph product tags.
- **`components/portfolio/VendorPortfolioView.tsx`**:
  - Render optional `"Store"` tab when the vendor has an active store with products.
- **`components/vendor-store/StorefrontView.tsx`**:
  - Responsive product grid with category filter chips, search, and sort order.
- **`components/vendor-store/StoreProductCard.tsx`**:
  - Product card with primary WebP image, title, price (with MRP strike-through), MOQ badge, and "Add to Order" button.
- **`components/vendor-store/StoreProductModal.tsx`**:
  - Lightbox detail modal with multi-image gallery, full description, and quantity selector.
- **`components/vendor-store/CartDrawer.tsx`**:
  - Slide-over mini-cart drawer displaying selected items, subtotal calculation, delivery city/state picker, and "Order via WhatsApp" button.
- **`components/vendor-store/ShareStoreButton.tsx`**:
  - Standalone store sharing modal with copy link, WhatsApp share, and local PNG QR code generation using `qrcode`.
